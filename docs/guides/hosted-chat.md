# Hosted Chat

Hosted Chat is now part of the unified WebUI Chat. The old standalone chat interface, model-profile configuration and archive format are superseded by the Controller's integrated chat and SQLite state.

Use the [WebUI Chat guide](../chat/index.md) for current documentation, including channels, Agents, memory, tools, permissions, scheduling, Goals and operations.

For a first setup, follow the [WebUI Chat quickstart](../getting-started/web-workspace.md).
