# البحث على الويب وقراءة المستندات في WebUI

البحث على الويب مفعّل افتراضياً في دردشة
WebUI. يمكن إيقافه لكل محادثة بواسطة المفتاح
الموجود أسفل مربع الرسالة، ويُحفظ الاختيار مع
المحادثة. لا تحتاج إلى مفتاح API من المزوّد
ولا إلى صلاحيات الصدفة الخاصة بـ Worker.

يحصل Agent على أداتين للقراءة فقط. تعيد
`web_search(query)` عناوين النتائج العامة
وروابطها وملخّصاتها. تستخدم `ddgs` عند
توفرها، وإلا تحاول Bing RSS دون مفتاح. قد
تفرض الخدمات العامة حدوداً على الطلبات أو
تتوقف مؤقتاً.

تقرأ `web_fetch(url, query?, offset?,
limit?)` ملفات HTML والنص العادي وJSON وXML
وMarkdown وPDF. عند فتح ملخّص arXiv تحاول
الحصول على النص الكامل بصيغة HTML ثم ملف PDF
إذا لم يتوفر. لا حاجة إلى واجهة بحث أكاديمية
منفصلة.

يُحفظ النص الكامل بعد أول قراءة في ذاكرة
تخزين خاصة على Controller إذا كان المجلد
قابلاً للكتابة. التخزين منفصل لكل مستخدم،
وتنتهي صلاحيته بعد 24 ساعة، وبحد أقصى 80
ملفاً لكل مستخدم. تعيد الأداة حتى 8000 حرف
عادة، ويمكن الاستمرار باستخدام الإزاحة أو
الحد أو عبارة البحث حتى 12000 حرف في الطلب.

يبلغ الحد الأقصى للتنزيل 20 MiB وللنص
المستخرج 3 MiB. تُرفض الشبكات الخاصة وبيانات
الاعتماد داخل الروابط والمنافذ غير المعتادة
وإعادات التوجيه غير الآمنة. تُجرى الاتصالات
بعناوين IP عامة تم التحقق منها لمنع هجمات DNS
rebinding.

يُحلّل PDF بواسطة PyMuPDF أو `pypdf` بديلاً.
تتطلب النسخ الممسوحة ضوئياً بلا طبقة نص تقنية
OCR، وتظهر رسالة خطأ صريحة. يُحترم ترميز HTML
المعلن وتُرفض الصيغ غير المدعومة.

تظهر الروابط في بطاقة نتيجة الأداة. ينبغي ذكر
الرابط الأصلي ورقم صفحة PDF متى أمكن. محتوى
المواقع الخارجية غير موثوق ولا يُسمح
لتعليماته بتغيير أوامر المستخدم أو إعدادات
Agent.

تُعاد محاولة صفحات HTML الفارغة أو المعتمدة على JavaScript باستخدام
Chromium دون واجهة وفي سياق جديد، إذا كانت حزمة browser الاختيارية والمتصفح مثبتين.
لا يُشغّل المتصفح للصفحات الثابتة أو PDF. يستخدم التصيير نفس ناقل HTTP
المقتصر على عناوين IP العامة، ويحظر الطلبات غير المخصصة للقراءة
والاتصال المباشر للمتصفح، بحد 25 ثانية و128 طلبًا.
قد تتعذر قراءة صفحات تتطلب تسجيل الدخول أو CAPTCHA أو عمليات إعادة توجيه غير مدعومة.
يُبلّغ عن رفض الوصول والنتائج الفارغة ولا تُخزّن مؤقتًا.
