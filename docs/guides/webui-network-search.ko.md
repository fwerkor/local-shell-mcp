# WebUI 웹 검색 및 문서 읽기

WebUI 채팅에서는 웹 검색이 기본으로 켜져 있습니다. 메시지 입력창 아래의 웹
검색 스위치로 대화마다 끌 수 있으며 선택 사항은 해당 대화에 저장됩니다. 공급자
API 키나 Worker 셸 권한은 필요하지 않습니다.

Agent에는 읽기 전용 도구 두 개만 제공됩니다.
`web_search(query)`는 공개 검색의 제목, URL 및 요약을
반환합니다. 설치되어 있다면 `ddgs`를 사용하고, 그렇지 않으면 키가 필요
없는 Bing RSS를 시도합니다. 공개 서비스의 제한으로 검색이 실패할 수
있습니다.

`web_fetch(url, query?, offset?, limit?)`는
HTML, 일반 텍스트, JSON, XML, Markdown, PDF를 읽습니다.
arXiv 초록에서는 가능한 경우 HTML 전문을 열고, 없으면 PDF를
시도합니다. 별도의 학술 검색 API는 필요 없습니다.

최초로 가져온 전체 본문은 Controller에서 사용자별 비공개 캐시에 최대
24시간 보관하며, 사용자당 최대 80개 문서로 제한됩니다. 기본 응답은
8000자 이하이고 위치, 길이 또는 검색어를 지정하여 더 읽을 수 있습니다. 한
번에 최대 12000자입니다.

다운로드는 최대 20 MiB, 추출 텍스트는 최대 3 MiB입니다. 내부 주소,
URL 자격 증명, 비표준 포트 및 위험한 리디렉션을 차단합니다. 확인된 공개
IP로만 연결하여 DNS 리바인딩을 방지합니다.

PDF는 PyMuPDF로 처리하고 필요하면 `pypdf`를 사용합니다. 텍스트
계층이 없는 스캔 PDF에는 OCR이 필요하며 오류를 명시적으로 반환합니다.
HTML의 문자 인코딩을 확인하고 지원되지 않는 형식은 거부합니다.

검색 링크는 도구 결과 카드에 표시됩니다. 답변에는 원본 URL과 PDF 페이지
번호를 가능한 한 인용해야 합니다. 외부 결과와 문서 내용은 신뢰할 수 없는
입력이므로 사용자 지시나 Agent 설정을 덮어쓸 수 없습니다.
