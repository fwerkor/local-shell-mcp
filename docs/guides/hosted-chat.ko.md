# Hosted Chat

호스팅된 채팅 기능은 이제 통합된 WebUI 채팅 시스템의 일부가 되었습니다. 기존의 독립적인 채팅 인터페이스, 모델 프로필 구성 및 아카이브 형식들은 모두 Controller의 통합된 채팅 기능과 SQLite 상태 관리 기능으로 대체되었습니다.

현재의 문서 내용을 확인하려면 [WebUI 채팅 가이드](../chat/index.md)를 참조하세요. 여기에는 채널, 에이전트, 메모리, 도구, 권한, 스케줄링, 목표 및 작업 관련 정보가 포함되어 있습니다.

처음으로 설정하는 경우, [WebUI 채팅 빠른 시작 가이드](../getting-started/web-workspace.md)을 따르세요.
