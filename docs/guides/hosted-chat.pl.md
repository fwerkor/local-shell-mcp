# Hosted Chat

Chaty hostowane są teraz częścią zintegrowanego interfejsu WebUI Chat. Stary, niezależny interfejs chatowy, konfiguracja profili modelowych oraz format plików archiwalnych zostały zastąpione przez funkcje chatowe włączone do kontrolera oraz dane przechowywane w bazie danych SQLite.

Użyj przewodnika [WebUI Chat](../chat/index.md) dla aktualnej dokumentacji, w tym dotyczącej kanali, agentów, pamięci, narzędzi, uprawnień, planowania, celów i operacji.

Aby przygotować system do użytku, prosimy o zgodność z [przewodnikiem dotyczącym szybkiego uruchomienia interfejsu WebUI Chat](../getting-started/web-workspace.md).
