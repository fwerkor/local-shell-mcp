# الدردشة المستضافة (اختياري)

الدردشة المستضافة عبارة عن دردشة BYOK وعميل MCP Apps مستضاف ذاتيًا ومدمج في الواجهة البشرية لـ LSM. إنه **ليس** وضع جلسة منطقية: المحادثات لها هويات مستقلة ويمكن اختياريًا إرفاق جلسة LSM منطقية موجودة. يستمر ChatGPT والعملاء الخارجيون الآخرون في العمل باستخدام نفس جلسات وأدوات LSM.

## تمكين

يتم تعطيل الدردشة المستضافة بشكل افتراضي. مجموعة:

```env
LOCAL_SHELL_MCP_HOSTED_CHAT_ENABLED=true
```

أعد تشغيل وحدة التحكم وافتح **الدردشة المستضافة** مباشرة أسفل محدد Web UI / TUI. تحتوي الميزة أيضًا على إدخال في الشريط العلوي للجوال. يستخدم مضيف الدردشة هوية ونطاقات LSM OAuth الموجودة. تقوم نفس وحدة التحكم بتشغيل خادم MCP الذي تستخدمه حلقة أداة النموذج؛ لا يمكن للعمال البدء في التنفيذ.

## ملفات تعريف النموذج

اختر **ملفات تعريف النماذج** لإنشاء/تحرير ملف تعريف باسم وعنوان URL الأساسي لواجهة برمجة التطبيقات المتوافقة مع HTTPS OpenAI ومعرف النموذج ومفتاح واجهة برمجة التطبيقات الاختياري. يمكن أن تتعايش ملفات تعريف متعددة ويمكن للمحادثات تبديل النماذج.

يتم حفظ الملفات الشخصية والمحادثات وسجل الرسائل الكامل ونتائج استدعاء الأداة **على الخادم** عبر الواجهة الخلفية لحالة LSM التي تم تكوينها. يرتبط نطاقها بالمبدأ المصادق عليه. يتم تشفير مفتاح API باستخدام AES-GCM ولا يتم إرجاعه مطلقًا من قائمة ملفات التعريف أو نقاط نهاية تفاصيل ملف التعريف. ولا يتم تخزينه في مساحة تخزين المتصفح، أو إرساله إلى النموذج كمطالبة، أو تضمينه في سجلات التدقيق. يقوم مضيف الدردشة بتمريرها فقط إلى واجهة برمجة التطبيقات للنموذج الذي تم اختياره.

ينشئ النشر الأول المدعوم بالملف `hosted-chat-encryption-key` في دليل الحالة باستخدام الوضع 0600. ** قم بعمل نسخة احتياطية لهذا الملف إلى جانب بيانات الحالة. بدونه، لا يمكن فك تشفير مفاتيح واجهة برمجة التطبيقات المحفوظة. ** إذا كانت وحدة التحكم تستخدم Redis أو نسخًا متماثلة متعددة أو واجهة خلفية أخرى غير حالة الملف، فقم بتكوين مفتاح URL-safe-base64 مستقر ومشترك بحجم 32 بايت:

```env
LOCAL_SHELL_MCP_HOSTED_CHAT_ENCRYPTION_KEY=<base64url-encoded 32 random bytes>
```

لا تقم بتدوير هذا الإعداد دون ترحيل ملفات التعريف المشفرة. لا تستخدم تخزين حالة الذاكرة في حالة الحاجة إلى إجراء محادثات دائمة.

افتراضيًا، يتم قبول نقاط نهاية نموذج HTTPS فقط بأسماء مضيفي DNS؛ يتم رفض نقاط النهاية المحلية/الخاصة وHTTP لتقليل مخاطر تزوير الطلب من جانب الخادم. يمكن للمسؤولين الذين يستضيفون بوابة نموذجية خاصة موثوقة عن عمد الاشتراك في:

```env
LOCAL_SHELL_MCP_HOSTED_CHAT_ALLOW_PRIVATE_ENDPOINTS=true
```

لا تقم بتمكين هذا على وحدة تحكم متعددة المستخدمين غير موثوق بها ما لم يتم السماح للمستخدمين بالاتصال بالخدمات الداخلية.

## المحادثات وتطبيقات MCP

قم بإنشاء محادثة باستخدام ملف تعريف النموذج المحفوظ. يصبح كل دور يتم إرساله مهمة خلفية مملوكة للخادم؛ إغلاق المتصفح لا يلغي المهمة. يتم فحص مكالمات النص والأداة المكتملة بشكل دائم بين خطوات النموذج/الأداة. توقف صراحة عن المقاطعة. عند إعادة تشغيل وحدة التحكم، يتم وضع علامة على عمليات التشغيل المتقطعة على هذا النحو ويمكن استمرارها في دورة جديدة، ولكن ** لا يتم إعادة تشغيل استدعاءات أداة النتيجة غير المعروفة تلقائيًا **.

يتم الاحتفاظ بسجل رسائل المحادثة بالكامل في وحدة التخزين. يتم إرسال نافذة حديثة محدودة فقط إلى النموذج مرة واحدة للتحكم في حجم السياق. يتم إرسال استدعاءات الأداة من خلال نقطة نهاية MCP الخاصة بـ LSM، مع الحفاظ على جميع أذونات الأداة العادية وسلوك التدقيق/الاختبار المبدئي.

تزيل الأرشفة المحادثات من القائمة العادية وتحفظها في `.json.zst` باستخدام برنامج ضغط zstd الموجود في Audit. لا تدخل المحادثات المؤرشفة في فهرس البحث العادي. يمكن العثور عليها بالعنوان من **Archived conversations** وقراءتها دون تعديل أو استعادتها أو حذفها نهائياً. تُكتب النسخة الجديدة قبل حذف القديمة لمنع فقدان البيانات.

### المحادثات الطويلة وضغط السياق

تبقى الرسائل الأصلية ونتائج الأدوات كاملة على الخادم. يمكن ضبط نافذة السياق في ملف تعريف النموذج؛ القيمة الافتراضية **32,768 رمزاً** والنطاق من 8,192 إلى 1,000,000. يشمل التقدير التحفظي المبني على UTF-8 تعريفات الأدوات. عند اقتراب الاستخدام من **80%** يلخّص النموذج نفسه الأدوار القديمة المكتملة مع الحفاظ على الأهداف والقيود والقرارات والملفات ونتائج الأدوات والمهام المتبقية. يُحفظ الملخص بصورة مستقلة، ولا يُرسل إلى النموذج سوى الملخص والرسائل الحديثة.

يُعاد حساب الميزانية بعد استدعاء الأدوات. يتيح **Compact** ضغط السياق يدوياً عندما لا توجد دورة قيد التشغيل. لا يغيّر الفشل الملخص السابق أو السجل الأصلي. عدد الرموز تقديري؛ تُرفض الدورة الحالية الكبيرة بدلاً من اقتطاعها بصمت.

افتح **مساحة العمل المباشرة** لعرض مورد `workspace_open` MCP Apps الموجود في LSM داخل طريقة عرض مضمنة. يستخدم المضيف جسر `@modelcontextprotocol/ext-apps` لدورة حياة التطبيق، وتجديد بيانات الاعتماد، واستدعاءات الأدوات، والإجراءات من شخص إلى وكيل. لم يتم تنفيذ أي مدير ملفات ثانٍ أو محطة طرفية أو تدقيق أو واجهة مستخدم وظيفية.

يتيح `session_id` الاختياري المرفق للدردشة المستضافة استخدام وعرض جلسة منطقية موجودة؛ ولا يعيد تصنيف الجلسة أو يمنح الدردشة المستضافة ملكيتها. معرفات محادثة الدردشة ومعرفات الجلسة المنطقية منفصلة.

## الحدود

- تستخدم طلبات النماذج عمليات إكمال الدردشة المتوافقة مع OpenAI مع استدعاء الأدوات؛ تتطلب بروتوكولات الموفر الأخرى محولاً.
- تحدد الإجراءات الوقائية لكل دورة تكرارات النماذج واستدعاءات الأدوات. قد تستمر المهام الأطول في دورة جديدة باستخدام التاريخ الدائم.
- حذف محادثة الدردشة صريح. لا يتم إجراء إخلاء التاريخ التلقائي.
- يجب أن تكون وحدة التحكم قابلة للوصول إلى الشبكة من خلال عميل MCP الخاص بها ويجب أن يكون المتصفح معتمدًا لـ LSM Live Workspace API.
