# Hosted Chat

الدردشة المُحجوزة أصبحت الآن جزءًا من واجهة الدردشة الموحدة في الويب. أما واجهة الدردشة القديمة، وتكوين النماذج، وصيغة الأرشيف، فقد تم استبدالها بخاصية الدردشة المتكاملة في البرنامج، بالإضافة إلى حالة SQLite.

استخدموا ذلك. [دليل استخدام واجهة الدردشة عبر الويب](../chat/index.md) للحصول على الوثائق الحالية، بما في ذلك القنوات، والوكلاء، والذاكرة، والأدوات، والصلاحيات، وجداول الأعمال، والأهداف، والعمليات المختلفة.

لإعداد النظام بشكل أولي، اتبع دليل التشغيل السريع الخاص بـ [WebUI Chat](../getting-started/web-workspace.md).
