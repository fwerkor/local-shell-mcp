# Hosted Chat

Hosted Chat artık birleşik WebUI Chat’in bir parçası haline geldi. Eski bağımsız sohbet arayüzü, model-profil yapılandırması ve arşiv formatları, Controller’ın entegre sohbet sistemi ve SQLite veri yapısına dönüştürüldü.

Mevcut dokümantasyon için [WebUI Chat rehberini kullanın](../chat/index.md). Bu rehberde kanallar, Agent’ler, bellek, araçlar, yetkilendirmeler, zamanlama, hedefler ve diğer işlemler hakkında bilgi bulabilirsiniz.

İlk kurulum için [WebUI Chat hızlı başlangıç kılavuzunu](../getting-started/web-workspace.md) takip edin.
