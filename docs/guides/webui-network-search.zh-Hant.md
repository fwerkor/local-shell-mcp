# WebUI 網路搜尋與文件閱讀

WebUI 聊天預設啟用網路搜尋。可在輸入框下方使用「網路搜尋」開
關，針對個別對話停用；設定會隨對話儲存。無須提供者 API
金鑰，也不需要 Worker 的 Shell 權限。

Agent
僅取得兩個內建唯讀工具。`web_search(query)`
回傳公開搜尋結果的標題、網址及摘要，優先使用
`ddgs`，否則嘗試免金鑰的 Bing
RSS；公開服務可能限制流量，因此無法保證每次成功。

`web_fetch(url, query?, offset?,
limit?)` 可讀取
HTML、純文字、JSON、XML、Markdown 與
PDF。對 arXiv 摘要頁，會先嘗試 HTML
全文，沒有時再嘗試 PDF，無須專用的論文 API。

第一次擷取的完整文字，在控制器快取目錄可寫時按使用者私密保存 24
小時，最多 80 份。預設單次顯示 8000
字元；可透過偏移、長度或關鍵字續讀，每次最多 12000 字元。

下載上限為 20 MiB，擷取文字上限 3 MiB。系統拒絕私人網
路、網址中的憑證、非標準連接埠與不安全轉址，並且只連接到已驗證的公
開 IP，以防止 DNS 重新綁定。

PDF 優先由 PyMuPDF 解析，失敗時使用
`pypdf`。沒有文字層的掃描版 PDF 需要
OCR，系統會明確報錯。HTML
依回應標頭或文件中的字元編碼解碼；不支援的格式會被拒絕。

搜尋連結顯示在工具結果卡片。回答應儘可能引用原始網址與 PDF
頁碼。外部搜尋片段與網頁內容不可信，其中的指令不得覆蓋使用者要求或
Agent 設定。
