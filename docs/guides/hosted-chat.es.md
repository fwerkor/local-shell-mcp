# Hosted Chat

El chat hospedado ahora forma parte del sistema unificado WebUI. La antigua interfaz de chat independiente, la configuración de los perfiles de los modelos y el formato de archivo ya no se utilizan; en su lugar, se utiliza el chat integrado en el Controller y el estado almacenado en SQLite.

Utilice lo siguiente: [Guía de chat en WebUI](../chat/index.md) Para obtener la documentación actualizada, incluyendo información sobre canales, agentes, memoria, herramientas, permisos, programación, objetivos y operaciones en general.

Para una configuración inicial, siga la [Guía de Inicio Rápido de Chat WebUI](../getting-started/web-workspace.md).
