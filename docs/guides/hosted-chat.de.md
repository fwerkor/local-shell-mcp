# Hosted Chat

Der Hosted Chat ist nun Teil der einheitlichen WebUI-Chat-Funktionalität. Die alte, separat stehende Chat-Oberfläche, die Konfiguration der Modelle sowie das Archivformat werden durch die integrierte Chat-Funktion des Controllers und die SQLite-Datenstruktur ersetzt.

Bitte verwenden Sie die [WebUI Chat-Anleitung](../chat/index.md) für weitere Informationen. Dabei handelt es sich um eine Dokumentation zu verschiedenen Funktionen wie Kanälen, Agenten, Speicher, Werkzeugen, Berechtigungen, Zeitplänen, Zielen und anderen Operationen.

Für eine erste Einrichtung folgen Sie dem [WebUI Chat-Kurzstartplan](../getting-started/web-workspace.md).
