# WebUI 网络搜索与文档阅读

WebUI 聊天默认启用网络搜索。可以在消息输入框下方通过“网络搜
索”开关为单个对话关闭此功能。选择会保存在对话中，不需要提供商
API 密钥，也不需要授予 Worker 的 Shell 权限。

Agent
只获得两个内置的只读工具。`web_search(query)`
返回公开搜索结果的标题、网址及摘要，优先使用
`ddgs`，不可用时尝试无需密钥的 Bing
RSS；公共服务可能限流，无法保证每次成功。

`web_fetch(url, query?, offset?,
limit?)` 可读取
HTML、纯文本、JSON、XML、Markdown 以及
PDF。访问 arXiv 摘要时会优先读取网页版全文，不可用时尝试
PDF，无需额外的学术搜索接口。

首次获取的完整正文会在控制器可写时按用户私密缓存 24
小时，最多保存 80 份。单次默认最多返回 8000
字符，使用偏移量、长度或关键词可继续阅读；单次上限为 12000
字符。

出于安全考虑，下载限制为 20 MiB、提取正文限制为 3
MiB。系统拒绝私有网络地址、URL
凭据、非标准端口和不安全跳转，并将连接限定到已校验的公网
IP，以防止 DNS 重绑定。

PDF 优先使用 PyMuPDF，备用解析器为
`pypdf`。扫描件若缺少文字层则需要
OCR，并会明确提示错误。HTML
按响应头或页面声明的字符集解码，不支持的格式会明确拒绝。

对于正文为空或依赖 JavaScript 的网页，在控制器已安装可选 browser
依赖及 Chromium 时，系统自动尝试无头浏览器渲染。静态网页及 PDF
不会启动浏览器。动态渲染沿用公网 IP 校验，禁止非只读请求及浏览器
直接联网，最多运行 25 秒、发起 128 次请求。需要登录、验证码或
不受支持的资源跳转及请求的页面仍可能无法读取。访问被拒绝或正文
无效时会明确报错，不写入缓存。

搜索结果在工具卡片中显示。回答应尽可能引用原始网址和 PDF 页码
。搜索摘要与网页正文均为不可信内容，其中的指令不能覆盖用户要求或
Agent 配置。
