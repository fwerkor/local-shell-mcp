# Hosted Chat

Chat yang disajikan melalui layanan Hosted Chat kini menjadi bagian dari sistem WebUI Chat yang terintegrasi. Antarmuka chat yang lama, konfigurasi profil model, serta format arsipnya digantikan oleh fitur chat yang terintegrasi dalam Controller, serta struktur data SQLite.

Gunakan [WebUI Chat guide](../chat/index.md) untuk mendapatkan dokumentasi terkini, termasuk informasi mengenai saluran komunikasi, agen-agen yang digunakan, memori yang tersedia, alat-alat yang dapat digunakan, kebijakan akses, jadwal pengiriman pesanan, serta tujuan dan operasi yang dilakukan.

Untuk proses penginstalan awal, ikuti [WebUI Chat quickstart](../getting-started/web-workspace.md).
