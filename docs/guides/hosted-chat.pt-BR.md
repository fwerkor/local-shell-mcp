# Hosted Chat

O Chat hospedado agora faz parte do sistema unificado WebUI. A antiga interface de chat independente, a configuração dos modelos e o formato de arquivo foram substituídos pelo chat integrado do Controller e pelo estado armazenado no SQLite.

Use o [Guia de chat via WebUI](../chat/index.md) Para a documentação atual, incluindo canais, agentes, memória, ferramentas, permissões, agendamento, metas e operações.

Para uma configuração inicial, siga o [Guia de Início Rápido do Chat WebUI](../getting-started/web-workspace.md).
