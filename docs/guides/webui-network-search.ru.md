# Веб-поиск и чтение документов в WebUI

В чате WebUI веб-поиск включён по умолчанию.
Его можно отключить для отдельной беседы
переключателем под полем сообщения; настройка
сохраняется для этой беседы. Ключ API
поставщика и доступ Worker к командной
оболочке не требуются.

Agent получает только два инструмента чтения.
`web_search(query)` возвращает заголовки, URL
и фрагменты общедоступных результатов.
Сначала используется `ddgs`, если он
установлен, иначе Bing RSS без ключа.
Публичные службы могут ограничивать запросы и
быть недоступны.

`web_fetch(url, query?, offset?, limit?)`
читает HTML, обычный текст, JSON, XML,
Markdown и PDF. Для страницы аннотации arXiv
сначала запрашивается полный текст в HTML,
затем PDF, если HTML недоступен. Отдельный
API научного поиска не нужен.

Полученный полный текст сохраняется в
закрытом кэше Controller, если каталог
доступен для записи. Кэш разделён по
пользователям, действует 24 часа и содержит
не более 80 файлов на человека. По умолчанию
возвращается до 8000 символов; поиск,
смещение и ограничение позволяют читать
следующие части, не более 12000 символов за
вызов.

Размер загрузки ограничен 20 МиБ,
извлечённого текста — 3 МиБ. Частные адреса,
учётные данные в URL, нестандартные порты и
опасные перенаправления запрещены.
Подключение идёт только к проверенным
публичным IP для защиты от DNS rebinding.

PDF обрабатываются через PyMuPDF или
резервный `pypdf`. Сканам без текстового слоя
нужен OCR, при его отсутствии выдаётся явная
ошибка. Кодировка HTML определяется по
объявлению; неизвестные форматы отклоняются.

Ссылки показываются в карточке результата
инструмента. В ответах рекомендуется
указывать исходные URL и страницы PDF.
Внешние тексты недоверенные и не могут
изменять инструкции пользователя или
настройки Agent.
