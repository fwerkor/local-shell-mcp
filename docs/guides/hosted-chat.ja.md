# Hosted Chat

ホストされたチャット機能は、今では統合されたWebUIチャットの一部となっています。以前の独立したチャットインターフェースや、モデル・プロファイルの設定、アーカイブ形式などは、もはや必要なくなりました。代わりに、Controller内で統合されたチャット機能やSQLiteによる状態管理が利用されるようになりました。

現在のドキュメントについては、[WebUIチャットガイド](../chat/index.md)を参照してください。ここには、チャンネル、エージェント、メモリ、ツール、権限、スケジュール、ゴールや操作に関する情報が含まれています。

初めて使用する場合は、[WebUIチャットのクイックスタートガイド](../getting-started/web-workspace.md)に従ってください。
