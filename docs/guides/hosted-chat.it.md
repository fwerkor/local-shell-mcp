# Hosted Chat

Il servizio di chat ospitato fa ora parte dell’interfaccia unificata WebUI Chat. L’antica interfaccia di chat indipendente, la configurazione dei modelli e il formato degli archivi sono stati sostituiti dal sistema di chat integrato presente nel Controller, nonché dalla struttura di dati gestita da SQLite.

Utilizzare il [Guida per l’uso della funzione di chat tramite WebUI](../chat/index.md) Per quanto riguarda la documentazione attuale, include informazioni sui canali di comunicazione, sugli agenti, sulla memoria, sugli strumenti utilizzati, sulle autorizzazioni, sulla gestione degli orari delle operazioni, nonché sugli obiettivi e sulle procedure da seguire.

Per una configurazione iniziale, seguire la [Guida all’uso della WebUI Chat](../getting-started/web-workspace.md).
