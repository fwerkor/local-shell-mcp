# Hosted Chat

Le chat hébergé fait désormais partie intégrante de l’interface WebUI unifiée. L’ancienne interface de chat indépendante, la configuration des modèles et le format d’archivage ont été remplacés par les fonctionnalités de chat intégrées dans le Controller, ainsi que par les données stockées dans SQLite.

Utilisez le [Guide de conversation via WebUI](../chat/index.md) Pour la documentation actuelle, il s’agit des canaux de communication, des agents, de la mémoire, des outils, des permissions, des horaires, des objectifs et des opérations en cours.

Pour une première configuration, suivez le [guide rapide du WebUI Chat](../getting-started/web-workspace.md).
