# WebUI のウェブ検索と文書の読み取り

WebUI
チャットではウェブ検索が既定で有効です。入力欄の下にある「ウェブ検索」で会話ごとに無効にできます。設定はその会話に保存されます。プロバイダーの
API キーや Worker のシェル権限は不要です。

Agent
には読み取り専用のツールが二つだけ公開されます。`web_search(query)`
は公開検索のタイトル、URL、概要を返します。`ddgs`
を優先し、使用できない場合はキー不要の Bing RSS
を試します。公開サービスの制限により結果を取得できない場合があります。

`web_fetch(url, query?, offset?, limit?)` は
HTML、テキスト、JSON、XML、Markdown、PDF を読み取ります。arXiv
の概要ページでは可能なら HTML 全文を取得し、なければ PDF を試します。論文専用
API は使いません。

初回取得時に全文を Controller
のユーザー別非公開キャッシュへ保存します。保存期間は 24 時間で、各ユーザー最大 80
件です。通常は最大 8000
文字を返し、位置、長さ、検索語を指定して続きを読み取れます。一度に返せる最大値は
12000 文字です。

ダウンロードは最大 20 MiB、抽出文字は最大 3 MiB
です。ローカルまたはプライベートネットワーク、URL
内の認証情報、標準外ポート、危険なリダイレクトを拒否します。確認済みの公開 IP
にだけ接続して DNS リバインディングを防ぎます。

PDF は PyMuPDF、必要に応じて `pypdf`
で解析します。文字層のないスキャン PDF には OCR
が必要で、明確なエラーを返します。HTML
は宣言された文字コードで読み取り、非対応形式は拒否されます。

検索結果はツール結果カードに表示されます。回答では元の URL と PDF
のページ番号を引用してください。外部ページの内容は信頼できない入力であり、Agent
の設定やユーザーの指示を書き換えることはできません。
