# Hosted Chat

Hosted Chat 現已成為統一 WebUI Chat 的一部分。舊版獨立聊天介面、模型配置及歸檔格式已由 Controller 整合聊天和 SQLite 狀態取代。

當前文件參見 [WebUI Chat 指南](../chat/index.md)，包括渠道、智慧體、記憶、工具、許可權、排程、Goal 與運維。

首次配置請閱讀 [WebUI Chat 快速入門](../getting-started/web-workspace.md)。
