# Hosted Chat

होस्टेड चैट, अब यूनिफाइड वेबयूआई चैट का हिस्सा है। पुरानी स्वतंत्र चैट इंटरफ़ेस, मॉडल-प्रोफ़ाइल कॉन्फ़िगरेशन, एवं आर्काइव फॉर्मेट, अब कंट्रोलर के एकीकृत चैट सिस्टम एवं सीडीआरओएल स्टेट सिस्टम द्वारा प्रतिस्थापित किए गए हैं।

वर्तमान दस्तावेज़ीकरण हेतु [WebUI चैट गाइड](../chat/index.md) का उपयोग करें। इसमें चैनलों, एजेंटों, मेमोरी, उपकरणों, अनुमतियों, शेड्यूलिंग, लक्ष्यों एवं अन्य संबंधित जानकारियाँ शामिल हैं।

पहले सेटअप हेतु، [WebUI Chat Quickstart](../getting-started/web-workspace.md) का अनुसरण करें।
