# WebUI में वेब खोज और दस्तावेज़ पढ़ना

WebUI चैट में वेब खोज डिफ़ॉल्ट रूप से चालू
रहती है। संदेश बॉक्स के नीचे दिए गए स्विच से
इसे किसी एक बातचीत के लिए बंद किया जा सकता
है। विकल्प उसी बातचीत में सहेजा जाता है।
प्रदाता की API कुंजी या Worker के शेल की
अनुमति आवश्यक नहीं है।

Agent को केवल दो पढ़ने वाले उपकरण मिलते हैं।
`web_search(query)` सार्वजनिक खोज के शीर्षक,
URL और संक्षिप्त विवरण लौटाता है। यह उपलब्ध
होने पर `ddgs` का उपयोग करता है, अन्यथा बिना
कुंजी के Bing RSS आज़माता है। सार्वजनिक
सेवाएँ अनुरोध सीमित कर सकती हैं या अनुपलब्ध
हो सकती हैं।

`web_fetch(url, query?, offset?, limit?)`
HTML, सामान्य पाठ, JSON, XML, Markdown और PDF
पढ़ सकता है। arXiv सार पृष्ठ पर यह पहले पूरा
HTML पाठ खोलता है और उपलब्ध न होने पर PDF
आज़माता है। अलग शोध API की ज़रूरत नहीं है।

पहली बार प्राप्त पूरा पाठ Controller की निजी
कैश में रखा जाता है, यदि निर्देशिका लिखने
योग्य हो। हर उपयोगकर्ता का कैश अलग है, 24
घंटे में समाप्त होता है और अधिकतम 80 फ़ाइलें
रखता है। सामान्य उत्तर 8000 अक्षरों तक होता
है; खोज, ऑफ़सेट और सीमा से आगे पढ़ सकते हैं,
एक बार में अधिकतम 12000 अक्षर।

डाउनलोड का आकार 20 MiB और निकाले गए पाठ का
आकार 3 MiB तक सीमित है। निजी नेटवर्क, URL में
पासवर्ड, असामान्य पोर्ट और असुरक्षित
रीडायरेक्ट रोके जाते हैं। DNS rebinding रोकने
के लिए कनेक्शन सत्यापित सार्वजनिक IP से ही
किया जाता है।

PDF पढ़ने के लिए PyMuPDF और विकल्प के रूप में
`pypdf` का प्रयोग होता है। पाठ परत रहित स्कैन
में OCR चाहिए और स्पष्ट त्रुटि मिलती है। HTML
की घोषित अक्षर एन्कोडिंग का सम्मान किया जाता
है और असमर्थित फ़ॉर्मैट अस्वीकार होते हैं।

खोज लिंक उपकरण परिणाम कार्ड में दिखते हैं।
उत्तर में जहाँ संभव हो मूल URL और PDF पृष्ठ
संख्या दें। बाहरी सामग्री अविश्वसनीय होती है
और उसके निर्देश उपयोगकर्ता के आदेश या Agent
सेटिंग नहीं बदल सकते।

खाली या JavaScript-निर्भर HTML पेज, वैकल्पिक browser extra और Chromium
स्थापित होने पर नए headless Chromium संदर्भ में फिर खोले जाते हैं।
स्थिर पेज और PDF ब्राउज़र शुरू नहीं करते। रेंडरिंग वही सार्वजनिक-IP-सीमित
HTTP परिवहन उपयोग करती है, गैर-पठन अनुरोध और सीधे ब्राउज़र नेटवर्क को रोकती है,
और 25 सेकंड व 128 अनुरोध तक सीमित है। लॉगिन, CAPTCHA और असमर्थित
रीडायरेक्ट या अनुरोध वाले पेज फिर भी अपठनीय हो सकते हैं।
अस्वीकृत पहुँच और खाली परिणाम रिपोर्ट किए जाते हैं, कैश नहीं होते।
