# Инструменты, машины и права доступа.

## Уровни авторизации.

Тот инструмент, который указан в списке, не гарантирует право на его использование. Эффективное разрешение требует учета ограничений, наложенных контроллером, полномочий подтвержденного пользователя, правил, действующих на машины, а также разрешений, предоставляемых инструментом. Одних лишь инструкций недостаточно для обеспечения доступа к данному инструменту.

Зарегистрированные машины, включая локального контроллера при его активации, по умолчанию имеют право на чтение и запись данных в соответствии с политикой обработки чатов. Однако в случае чувствительных ситуаций необходимо ограничить эти права. Названия неизвестных машин не получают никаких прав для доступа к данным. Контроллер может отключать возможность выполнения операций локально или в режиме удаленного выполнения.

## Доступ к машинам

| Аксессуары | Значение |
|---|---|
| Нет | Операции с машинами недоступны. |
| Только чтение | Разрешается выполнение только операций, которые считаются операциями только для чтения. Использование скриптов или Python не является операцией только для чтения. |
| Чтение/запись | Разрешается выполнение операций чтения, изменения и выполнения данных, при условии соблюдения других ограничений. |
| Наследовать | Использовать соответствующие параметры высокого уровня, а не явные переключения параметров. |

![Разрешения и режим одобрения использования устройства в процессе общения](../assets/chat/machine-permissions.png)

Задавайте глобальные значения по умолчанию, переопределения проекта и отдельных чатов в настройках разрешений машин. Переопределения чата имеют приоритет над настройками проекта, а настройки проекта — над глобальными. Agent может дополнительно ограничивать доступ к каждой машине или своей политикой по умолчанию; его явные разрешения не обходят ограничения аутентифицированного субъекта или Controller.

Пример: глобальная политика чтения и записи, переопределение проекта «только чтение» и разрешение Agent на чтение и запись дают доступ только для чтения в чате этого проекта, если политика чата явно не переопределяет его. Но даже переопределение чата на чтение и запись не может превысить ограничение Agent «только чтение».

Установленная сессия с использованием определенного агента включает в себя политику этого агента, а также сохраненные параметры выполнения задач. При этом не передаются обычные настройки чата-машины. См. раздел [Цели и автоматизация](automation.md). Для выполнения неотложных задач используйте специальный агент с ограниченными правами.

## Удовлетворение требований к инструменту

| Форма, стиль | Поведение |
|---|---|
| Автоматический | Приемы вызова с использованием разрешенных инструментов происходят без необходимости получения дополнительного разрешения, если только не предусмотрено иное в отдельной политике. |
| Обзор рискованных операций | Управляющий запрашивает проверку операций, которые считаются опасными. Среди таких операций могут быть произвольные команды, выполняемые в командной строке, а также множество внешних вызовов. |
| Обзор всех инструментов | Необходимо получить разрешение на использование обычных инструментов. |

Настройки подтверждения чата могут наследовать настройки Agent и глобальные значения. Существующие явные правила отказа или подтверждения продолжают действовать. Дочерний Agent не может ослабить режим подтверждения родителя. Подтверждение не зависит от разрешений: подтверждение запрещённого действия на машине не предоставляет доступ к ней.

Перед утверждением необходимо тщательно рассмотреть все аргументы, цели и возможные побочные эффекты. Для неконтролируемых процессов необходимо тщательно настроить параметры агента и правила утверждения. Не следует расширять доступ к функциям, лишь для того, чтобы устранить необходимость в дополнительных действиях.

## Национальные и внешние инструменты MCP

Национальные инструменты работают с Controller и зарегистрированными Workers через LSM. Реестр инструментов включает в себя функции для работы с файлами, обработки команд в шелле и на браузере, а также функции для работы в режиме GUI. Также в реестре есть функции для удаленного обнаружения устройств, логические сессии и другие функции. Для получения точных описаний параметров использования инструментов смотрите раздел [Инструменты](../reference/tools.md). Для информации о способах объединения устройств с помощью удаленного работающего сервера смотрите раздел [Удаленные рабочие станции](../guides/remote-workers.md).

Управлять вложенными серверами MCP в WebUI. Поддерживаются следующие конфигурации: локальный стандартный интерфейс и удаленный HTTP-порт. Также возможно использование специфичных для сервера переменных окружения или заголовков. Необходимо включить функциональность MCP для чата и соответствующих агентов. Агент может обнаруживать, проверять и использовать доступные внешние инструменты. Однако процедуры авторизации и одобрения использования этих инструментов все еще применяются.

Внешний инструмент MCP может работать независимо от встроенных ACL машин: внешний удалённый API способен изменять ресурсы даже при отключённом доступе к локальным машинам. Проверяйте разрешения и учётные данные внешней службы отдельно. Не устанавливайте недоверенные stdio-серверы на Controller, содержащем конфиденциальные файлы.

## Запросите мнение пользователей и решайте вопросы, связанные с включением/отключением определенных функций.

Функция “Ask User” позволяет агенту запрашивать структурированные человеческие данные вместо того, чтобы пытаться самостоятельно вычислять их. Ответы на запросы формируются с использованием предоставленных инструкций. Речь идет о запросе информации, а не о разрешении на обход процедур, которые были отклонены. Когда задача остается без внимания, необходимо указать агенту, как справляться с неопределенностями и как обрабатывать ожидающие сообщения перед тем, как считать задачу выполненной.

Композитор описывает такие функции управления, как поиск в сети, использование внешних ресурсов и управление памятью. Эти функции определяют, какие возможности доступны для модели. Они не связаны с процедурами авторизации; отключение какой-либо функции не уничтожает сохраненные результаты работы модели. Поиск в сети включен по умолчанию, а для его использования используются только для чтения данные из веб-инструментов, как описано в разделе [Поиск в сети](../guides/webui-network-search.md).

## Аудит и проверка

Проверяйте вызовы инструментов и результаты их работы в чате; расширяйте информацию при диагностике неполадок. Журнал аудита контроллера отображает информацию о деятельности нативных инструментов, а задачи/сессии показывают процесс выполнения операций. Успешный ответ API означает, что инструмент вернул результат, но это не гарантирует, что запрошенная внешняя операция была выполнена успешно. Проверяйте данные о записях, статусе удаленных задач и состоянии развертывания отдельно. См. [Журнал аудита](../guides/audit-log.md).
