# WebUI Chat

LSM WebUI Chat 是整合於 Controller 的自託管 AI 智慧體工作區。接入自己的模型 API 或受支援的帳戶後，即可讓模型使用你的工具和機器。無需額外的 MCP 客戶端；外部客戶端仍可獨立連線同一個 Controller。

## 核心概念

- **Controller：** Python 服務，負責瀏覽器介面、模型請求、工具執行、排程和持久化狀態。
- **渠道（Channel）：** 模型 API 或帳戶授權連線，具有獨立的憑證、協議、模型列表和設定。
- **模型：** 某一渠道下的模型標識。同名模型位於不同渠道時不代表使用同一端點。
- **智慧體（Agent）：** 可複用的模型、指令、工具、Skill 與權限設定。
- **會話：** 儲存訊息、設定、執行歷史和模型/智慧體關聯。
- **專案：** 對相關會話進行分組，並提供共享的預設設定。
- **Worker：** 主動連線 Controller 的執行節點，並非模型提供方或獨立聊天服務。
- **邏輯會話（Logical Session）：** 工具側持久化任務標識，與聊天會話 ID 不同，可用於記錄目標、進度和工具工作。

模型 API 接收模型可見的上下文及工具結果，Controller 執行授權工具。模型不會直接連線 Worker，也不會獲得你的模型 API Key。瀏覽器用於呈現會話並控制 Controller。

## 使用原則

從已知機器上的小範圍只讀任務開始，檢查工具結果後再允許修改。工具成功也不代表模型判斷正確。模型憑證、會話儲存、機器權限與工具審批彼此獨立，修改其中一項不會自動授權其他操作。公開部署的聊天入口應當按照遠端執行控制面的安全要求保護。

外部 MCP 客戶端接入參見[連線方式](../clients/connectivity.md)，底層工具引數參見[工具參考](../reference/tools.md)。
