# WebUI Chat

LSM WebUI Chat은 컨트롤러에 내장된 자체 호스팅된 AI 에이전트 작업 공간입니다. 자신만의 모델 엔드포인트나 지원되는 계정을 사용할 수 있으며, 모델에게는 자신의 도구와 기기들을 사용할 수 있는 권한을 부여할 수 있습니다. 외부의 MCP 클라이언트가 필요하지 않습니다. 외부 클라이언트도 여전히 컨트롤러에 독립적으로 연결될 수 있습니다.

## 모든 조각들이 어떻게 맞아떨어지는지

- **Controller:** 브라우저 애플리케이션을 호스팅하고, 요청을 처리하며, 도구를 실행하고, 작업을 스케줄링하며, 지속적인 상태를 관리하는 파이썬 서비스입니다.
- **채널:** 모델 API 연결이나 지원되는 계정 인증 방식을 의미합니다. 각 채널에는 고유한 자격 증명, 프로토콜, 모델 목록 및 설정이 있습니다.
- **모델:** 채널 내에서 사용되는 모델 식별자입니다. 두 개의 채널에서 같은 식별자를 사용한다고 해서 반드시 동일한 엔드포인트를 의미하지는 않습니다.
- **엔티티:** 모델, 지침, 도구, 스킬, 권한 등을 결합하여 재사용할 수 있는 구조입니다.
- **대화 내용:** 저장된 메시지들, 설정 정보, 실행 기록, 그리고 모델/에이전트와의 연관성 정보입니다.
- **프로젝트:** 공통된 기본 설정들을 가진 여러 대화들의 집합입니다.
- **작업자**: 외부와 연결된 실행 대상입니다. 이는 모델 제공자나 별도의 채팅 서버가 아닙니다.
- **논리적 세션:** 도구 측에서의 지속적인 작업을 나타내는 개념입니다. 이는 대화 ID와는 다른 개념입니다. 채팅에서는 이를 사용하여 목표나 진행 상황, 그리고 도구를 활용한 작업을 추적할 수 있습니다.

이 모델 API는 모델이 볼 수 있는 컨텍스트와 도구의 결과를 받습니다. Controller는 허가된 도구들을 실행합니다. 모델은 직접 Worker에 연결하거나 모델 API 키를 얻지 않습니다. 브라우저가 대화 내용을 표시하고 Controller를 제어합니다.

## 기본 원칙들.

알려진 머신에서 제한된 범위의 읽기 전용 요청으로 시작합니다. 수정하기 전에 도구의 출력을 확인해야 합니다. 도구가 성공하더라도 모델이 잘못될 수 있습니다. 모델 인증 정보, 채팅 저장소, 머신 접근 권한, 도구 승인은 별개의 문제입니다. 하나를 변경해도 다른 것을 자동으로 얻는 것은 아닙니다. 특히, 공개된 채팅 엔드포인트는 원격 실행 제어 플레이트로 보호되어야 합니다.

외부 MCP 클라이언트 경로에 대해서는 [클라이언트 연결](../clients/connectivity.md)을 참조하십시오. 도구의 인수에 대해서는 [도구 참조](../reference/tools.md)를 참조하십시오.
