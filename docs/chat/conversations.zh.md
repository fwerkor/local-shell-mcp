# 会话与项目

## 创建和继续聊天

新建会话，选择渠道/模型或智能体，输入消息。聊天在 Controller 上运行，通过流式响应更新浏览器。刷新页面或关闭标签页不等于取消执行。需要中断时使用停止控件，并检查执行状态后再开始其他操作。

已保存会话保留模型/智能体关联。需要不同模型时明确切换。聊天会话保存用户和模型消息，Logical Session 则保存工具侧任务目标、进度与计划。交接长任务时保留相关标识。

## 整理和查找工作

用项目组织相关会话、设置共享机器权限默认值。一个项目可以包含多个独立聊天。将会话移动到适当项目或在项目中创建会话，不要假定不同会话共享全部上下文。当前项目信息可以帮助智能体了解会话归属。

标签用于分类会话；消息书签指向具体消息，便于回到有用结果。这两个功能与置顶会话不同。可以使用会话标题、搜索、归档和未读状态管理侧边栏。

归档将会话从普通列表移出而不删除历史，需要时可从归档界面恢复。删除会话是破坏性操作，不应代替归档。当前实现使用 SQLite 会话状态，不再假定旧版 Hosted Chat 的压缩归档格式。

## 消息操作与运行中的任务

可用的消息控件取决于消息与执行状态。可按需编辑、重试或删除选定的用户/助手轮次。删除会改变持久历史，并可能影响后续上下文，但不会撤销 Shell 命令、远程写入、Git push 或其他外部副作用。

重试失败任务前，先查看详细错误和已经完成的工具调用。如果写操作可能在断线前成功，应检查外部状态再决定是否重试。如果已有消息排队或正在推理，参考界面控件和状态，不要假定同一会话中的多个轮次可以并行执行。排队消息面板可查看待执行轮次；Steer 控件尝试在当前工具执行完成后的安全边界插入新指导。这两种操作都不会撤销已完成工具的副作用。

## 附件、预览和文件产物

通过附件控件上传文件或受支持的图片。单个附件实现上限为 32 MiB，部署和代理的请求限制可能使有效上限更低。上传文件保存在 Controller，可供模型引用。图片理解要求模型和提供方支持图像输入。上传不会授予访问其他本地或远程文件的权限。

要求生成文件时，明确路径、格式和内容，分享前检查文件实际存在。可在聊天中下载或预览支持的附件及产物。Worker 上生成的文件可能需要传回 Controller 或创建合适的文件链接。参见[文件链接](../guides/file-links.md)。

Artifact 渲染可以在侧面板展示 React、HTML、SVG、Markdown 和 Mermaid，而不仅是代码块。智能体 Artifact 设置中，Normal 使用标准指令，shadcn/ui 增加组件库指导，Custom 保留渲染能力但不注入内置 Artifact 指令。生成代码和渲染内容应视为不可信，在预览之外使用前先审查。Office 文件预览、下载与生成式 UI Artifact 是不同能力。

不要上传凭证、私钥或无权提交给所选模型提供方的文档。删除附件或会话，与删除机器上的源文件是不同操作。

## 偏好设置

工具开关、键盘快捷键等会话与用户偏好可在 WebUI 管理，已实现的设置在服务端持久化。通过设置页面配置键盘行为，区分发送消息与插入换行。会话工具开关与智能体权限分别设置。参见[工具与权限](permissions.md)及[记忆与上下文](context.md)。

### 自动命名会话

在设置 → 聊天 → 会话中，可选择不自动命名、新会话命名一次或每回合都重命名。默认使用会话原模型为新会话命名一次，也可以从已配置渠道中指定其他模型。命名仅在主模型完整回复结束后执行；主回复失败或被取消时不触发。标题用用户的语言简明说明当前任务。命名请求独立于会话上下文，不增加聊天消息。
