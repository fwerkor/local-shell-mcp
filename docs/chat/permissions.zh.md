# 工具、机器与权限

## 授权层级

工具出现在列表中并不保证可以执行。实际授权结合 Controller 限制、已认证身份的 Scope、机器策略、智能体能力和工具审批。提示词无法单独强制执行权限。

对于已注册机器（包括启用的 Controller 本地执行目标），聊天机器策略默认读写。敏感部署应收紧默认值。未知机器名不会获得隐式授权。Controller 可以分别禁用本地执行和远程 Worker。

## 机器权限

| 权限 | 含义 |
|---|---|
| 无 | 不可执行机器操作 |
| 只读 | 仅允许归类为只读的操作；任意 Shell/Python 执行不属于只读 |
| 读写 | 在其他限制范围内允许授权的读取、修改及执行操作 |
| 继承 | 使用适用的上级默认值，而非显式覆盖 |

![会话中的机器权限及审批模式面板](../assets/chat/machine-permissions.png)

在机器权限控件中设置全局默认值、项目覆盖和会话覆盖。具体会话覆盖优先于项目覆盖，后者优先于全局默认。智能体可以通过逐机器设置或默认策略进一步限制权限；显式智能体权限不会绕过身份 Scope 或 Controller 限制。

例如，全局读写、项目只读、智能体读写时，该项目会话权限为只读，除非会话显式覆盖项目设置。即使会话设为读写，也无法超过智能体的只读上限。

使用指定智能体运行定时任务时，采用智能体机器策略及保存的授权 Scope，而非普通聊天机器覆盖。参见[Goal 与自动化](automation.md)。无人值守任务应使用单独的受限智能体。

## 工具审批

| 模式 | 行为 |
|---|---|
| 自动 | 授权工具调用无需额外审批，除非其他显式策略要求 |
| 危险操作 | Controller 对归类为危险的操作要求审核，包括任意 Shell 命令和多种外部调用 |
| 全部 | 普通工具调用需要审批 |

聊天审批设置可以继承智能体和全局默认。已有显式拒绝或审批规则仍然有效。子智能体不能弱化父智能体审批模式。审批与权限独立，批准一个被拒绝的机器操作不会授予机器访问权限。

批准前查看实际参数、目标和潜在副作用。无人值守工作流应审慎设置智能体及审批策略；必须人工确认的操作可能阻塞进度。不要仅为减少提示而扩大权限。

## 原生与外部 MCP 工具

原生工具通过 LSM 在 Controller 及已注册 Worker 上操作，包括文件、Shell 与 Job、浏览器与 GUI、远程发现、逻辑会话等。精确参数见[工具参考](../reference/tools.md)，机器加入方式见[远程 Worker](../guides/remote-workers.md)。

在 WebUI 管理嵌套 MCP 服务器。支持本地 stdio 和远程 HTTP 传输，可配置各服务器的环境变量或请求头。在聊天和相关智能体中启用外部 MCP 能力。智能体可以发现、检查和调用可用外部工具，仍然受到相关授权和审批约束。

外部 MCP 工具可能独立于原生机器权限，例如禁用本地机器访问后，外部远程 API 仍可能修改资源。因此应分别审查外部服务权限和凭证。不要在持有敏感文件的 Controller 上安装不可信的 stdio 服务。

## Ask User 与功能开关

Ask User 允许智能体请求结构化人工输入，避免自行猜测。通过界面展示的问题控件回答。这是信息请求，不能用于绕过拒绝的工具权限。无人值守时，应明确如何处理不确定性，并在认定任务完成前检查待处理交互。

输入区提供网络搜索、外部 MCP、记忆等功能控制。这些开关决定模型可使用的能力，与授权独立；关闭功能不会删除历史结果。网络搜索默认开启，使用[网络搜索](../guides/webui-network-search.md)所述只读 Web 工具。

## 审计和验证

在聊天中检查工具调用及结果，排障时展开折叠的详情。Controller 审计日志记录原生工具活动，Job/Session 可用于查看持续执行。API 返回成功只代表工具返回结果，不保证外部操作达到目标。应独立验证写入、远程任务状态和部署健康情况。参见[审计日志](../guides/audit-log.md)。
