# Goal、定時會話與長任務

## 選擇合適的機制

| 機制 | 用途 |
|---|---|
| 普通聊天推理 | 響應當前提示詞，包括工具呼叫 |
| Chat Goal | 在模型輪次之間繼續執行活躍的邏輯會話計劃 |
| 定時會話 | 按週期使用已儲存提示詞啟動智慧體 |
| 持久 Job 或終端 | 獨立於單次模型請求執行命令 |
| 子智慧體 | 將明確任務委派至另一個智慧體執行緒 |

定時會話不是持久 Shell Job。Logical Session 也不是聊天會話或作業系統程序。取消其中一項不一定會停止其工具啟動的所有任務。

## Chat Goal

對於長任務，要求智慧體明確目標，並使用邏輯會話工具維護計劃。計劃記錄步驟及其狀態。聊天執行時可以在模型輪次結束時繼續活躍計劃，無需等待新使用者訊息或外部 MCP Live Workspace 的空閒計時器。

檢查計劃和進展，透過可用的 Goal 控制元件暫停、恢復或取消。續跑需要活躍計劃及符合條件的執行，不應繼續已完成、阻塞或取消的計劃。連續收到無進展的相同回覆時會暫停（當前為三個未變化的邊界），以避免無限迴圈。恢復前先解決實際阻塞。

明確完成標準。例如：檢查倉庫、實現修復、執行相關測試並報告失敗。要求智慧體記錄具體 commit ID 和測試結果，而非僅憑計劃狀態宣告成功。

外部 MCP 客戶端 Goal 機制不同，Logical Session 和 Live Workspace 交接參見[人機介面](../guides/human-interface.md)。

## 建立定時會話

![含已停用範例任務的定時會話側欄](../assets/chat/scheduled-chats.png)

開啟定時會話管理，建立包含描述性名稱、已儲存智慧體、提示詞、時區和週期的任務。選擇目標會話，新建會話時可選專案，儲存並啟用。正式使用前，利用手動執行控制元件驗證設定。

週期支援每小時、每天、工作日、每週、五欄位 cron 及連續執行。連續執行按設定的延遲啟動後續輪次；零延遲可能持續佔用模型與機器資源。普通週期任務最短間隔為五分鐘。使用明確的 IANA 時區，如 `Asia/Shanghai` 或 `UTC`，儲存後檢查下一次執行時間。

工作日 09:00 的 cron 示例：

```text
0 9 * * 1-5
```

這使用指定時區，而不一定是 Controller 系統時區。對於實行夏令時的時區，應注意切換日期。

## 會話目標

- **每次新增會話:** 每次執行獨立新建，適用於獨立報告。
- **重複使用同一會話:** 首次執行建立，後續複用，適用於持續監控。
- **指定既有會話:** 選擇接收定時訊息的現有會話。

複用或已有會話會逐漸增長，並可能觸發上下文壓縮。不需要歷史時可使用獨立會話。定時執行要求所選智慧體及模型渠道仍然存在且可用。

## 無人值守權限

定時執行由 Controller 管理，儲存授權 Scope 名稱，而非瀏覽器登入 Token。必要時儲存或手動執行任務完成授權。指定智慧體的機器權限生效，普通專案/聊天機器覆蓋不是定時任務機器策略。Controller 限制、儲存的授權、工具能力和審批仍然有效。

對於需要認證的外部 MCP 伺服器，互動式登入不自動意味著具備可續期的無人值守授權。如果定時任務介面提示重新認證或需要設定無人值守訪問，啟用任務前處理對應伺服器憑證，或移除該依賴。不要使用瀏覽器 Token 替代授權。

使用只讀智慧體進行監控，明確允許的目標、輸出和禁止操作。如果定時任務需要人工回答或審批，檢查待處理互動；無人值守不等於無限制訪問。監控提示詞示例：

```text
檢查指定訓練任務及其日誌。
報告當前步數、loss、吞吐率、ETA 和新增錯誤。
不要修改檔案、重啟任務或啟動新工作。
資料不可用時，報告具體原因。
```

## 生命週期與恢復

Controller 持久化定時任務與執行狀態，並以事務認領每次執行，避免重複啟動。瀏覽器不必保持開啟。不要假定遺漏的週期都會補跑，也不要假定所有外部任務都能跨 Controller 重啟繼續。停機後檢查上次執行、下次執行、正在執行的任務及相關會話。

禁用定時任務可阻止後續自動執行。正在執行的輪次應單獨檢查；停止未來排程不保證取消正在執行的推理或 Shell Job。移除不再需要的任務，並撤銷多餘智慧體權限。

WebUI 智慧體建立的 tracked Job 或終端可以在正常模型響應完成後繼續執行；Controller 重啟本身也不一定終止它。顯式中止、機器權限丟失或授權過期可能觸發智慧體所屬任務的取消。如果 Worker 離線，取消可能保持待處理，直到能夠送達。確認執行已經停止前，應直接檢查 Job 或終端狀態。透過受保護的 WebUI 工具路徑，智慧體只能向本會話所屬的 Job/Shell 傳送操作或停止它們。外部 MCP 客戶端保留原生語義。

智慧體後臺工具與子智慧體任務具有各自生命週期。即使執行完成，結果也可能仍在等待投遞；檢查會話後臺任務面板，獲取結果或等待已設定的喚醒機制恢復父智慧體。不要僅因結果尚未顯示就啟動重複任務。

需要跨單次工具請求執行的命令，應使用 LSM tracked Job 或持久終端。將輸出儲存到日誌檔案，記錄 Job 標識，檢查實際進展。參見[使用模式](../guides/usage-patterns.md)。
