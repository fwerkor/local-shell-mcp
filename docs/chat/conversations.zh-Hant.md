# 會話與專案

## 建立和繼續聊天

新建會話，選擇渠道/模型或智慧體，輸入訊息。聊天在 Controller 上執行，透過流式響應更新瀏覽器。重新整理頁面或關閉標籤頁不等於取消執行。需要中斷時使用停止控制元件，並檢查執行狀態後再開始其他操作。

已儲存會話保留模型/智慧體關聯。需要不同模型時明確切換。聊天會話儲存使用者和模型訊息，Logical Session 則儲存工具側任務目標、進度與計劃。交接長任務時保留相關標識。

## 整理和查詢工作

用專案組織相關會話、設定共享機器權限預設值。一個專案可以包含多個獨立聊天。將會話移動到適當專案或在專案中建立會話，不要假定不同會話共享全部上下文。當前專案資訊可以幫助智慧體瞭解會話歸屬。

標籤用於分類會話；訊息書籤指向具體訊息，便於回到有用結果。這兩個功能與置頂會話不同。可以使用會話標題、搜尋、歸檔和未讀狀態管理側邊欄。

歸檔將會話從普通列表移出而不刪除歷史，需要時可從歸檔介面恢復。刪除會話是破壞性操作，不應代替歸檔。當前實現使用 SQLite 會話狀態，不再假定舊版 Hosted Chat 的壓縮歸檔格式。

## 訊息操作與執行中的任務

可用的訊息控制元件取決於訊息與執行狀態。可按需編輯、重試或刪除選定的使用者/助手輪次。刪除會改變持久歷史，並可能影響後續上下文，但不會撤銷 Shell 命令、遠端寫入、Git push 或其他外部副作用。

重試失敗任務前，先檢視詳細錯誤和已經完成的工具呼叫。如果寫操作可能在斷線前成功，應檢查外部狀態再決定是否重試。如果已有訊息排隊或正在推理，參考介面控制元件和狀態，不要假定同一會話中的多個輪次可以並行執行。排隊訊息面板可檢視待執行輪次；Steer 控制元件嘗試在當前工具執行完成後的安全邊界插入新指導。這兩種操作都不會撤銷已完成工具的副作用。

## 附件、預覽和檔案產物

透過附件控制元件上傳檔案或受支援的圖片。單個附件實現上限為 32 MiB，部署和代理的請求限制可能使有效上限更低。上傳檔案儲存在 Controller，可供模型引用。圖片理解要求模型和提供方支援影象輸入。上傳不會授予訪問其他本地或遠端檔案的權限。

要求生成檔案時，明確路徑、格式和內容，分享前檢查檔案實際存在。可在聊天中下載或預覽支援的附件及產物。Worker 上生成的檔案可能需要傳回 Controller 或建立合適的檔案連結。參見[檔案連結](../guides/file-links.md)。

Artifact 渲染可以在側面板展示 React、HTML、SVG、Markdown 和 Mermaid，而不僅是程式碼塊。智慧體 Artifact 設定中，Normal 使用標準指令，shadcn/ui 增加元件庫指導，Custom 保留渲染能力但不注入內建 Artifact 指令。生成程式碼和渲染內容應視為不可信，在預覽之外使用前先審查。Office 檔案預覽、下載與生成式 UI Artifact 是不同能力。

不要上傳憑證、私鑰或無權提交給所選模型提供方的文件。刪除附件或會話，與刪除機器上的原始檔是不同操作。

## 偏好設定

工具開關、鍵盤快捷鍵等會話與使用者偏好可在 WebUI 管理，已實現的設定在服務端持久化。透過設定頁面設定鍵盤行為，區分傳送訊息與插入換行。會話工具開關與智慧體權限分別設定。參見[工具與權限](permissions.md)及[記憶與上下文](context.md)。

### 自動命名會話

在設定 → 聊天 → 會話中，可選擇不自動命名、新會話命名一次或每回合都重新命名。預設使用會話原模型為新會話命名一次，也可以從已設定渠道中指定其他模型。命名僅在主模型完整回覆結束後執行；主回覆失敗或取消時不觸發。標題以使用者的語言簡明說明目前任務。命名請求獨立於會話上下文，不增加聊天訊息。
