# WebUI Chat

LSM WebUI Chat 是集成于 Controller 的自托管 AI 智能体工作区。接入自己的模型 API 或受支持的账户后，即可让模型使用你的工具和机器。无需额外的 MCP 客户端；外部客户端仍可独立连接同一个 Controller。

## 核心概念

- **Controller：** Python 服务，负责浏览器界面、模型请求、工具执行、调度和持久化状态。
- **渠道（Channel）：** 模型 API 或账户授权连接，具有独立的凭证、协议、模型列表和设置。
- **模型：** 某一渠道下的模型标识。同名模型位于不同渠道时不代表使用同一端点。
- **智能体（Agent）：** 可复用的模型、指令、工具、Skill 与权限配置。
- **会话：** 保存消息、设置、执行历史和模型/智能体关联。
- **项目：** 对相关会话进行分组，并提供共享的默认配置。
- **Worker：** 主动连接 Controller 的执行节点，并非模型提供方或独立聊天服务。
- **逻辑会话（Logical Session）：** 工具侧持久化任务标识，与聊天会话 ID 不同，可用于记录目标、进度和工具工作。

模型 API 接收模型可见的上下文及工具结果，Controller 执行授权工具。模型不会直接连接 Worker，也不会获得你的模型 API Key。浏览器用于呈现会话并控制 Controller。

## 使用原则

从已知机器上的小范围只读任务开始，检查工具结果后再允许修改。工具成功也不代表模型判断正确。模型凭证、会话存储、机器权限与工具审批彼此独立，修改其中一项不会自动授权其他操作。公开部署的聊天入口应当按照远程执行控制面的安全要求保护。

外部 MCP 客户端接入参见[连接方式](../clients/connectivity.md)，底层工具参数参见[工具参考](../reference/tools.md)。
