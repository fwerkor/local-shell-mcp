# チャットとプロジェクト

## チャットを作成し、続行する。

新しいチャットを開始し、チャンネル/モデルまたはAgentを選択してメッセージを入力します。チャットはController上で実行され、更新情報がブラウザに表示されます。ページを再読み込みしたり、タブを閉じたりしても、実行をキャンセルすることにはなりません。停止コントロールを使って実行を中断し、別の操作を開始する前に結果の状態を確認してください。

保存されたチャットは、そのモデルやエージェントとの関連性を保持します。別のモデルを使用したい場合は、意図的に切り替えることができます。会話は「論理的なセッション」ではありません。会話にはユーザーからのメッセージやモデルからのメッセージが含まれます。一方、論理的なセッションには、ツール側のタスクの目的や進捗状況、計画などが含まれます。長期にわたるタスクを引き継ぐ際には、関連するIDを保持しておくことが重要です。

## 仕事を整理し、探す。

プロジェクトを使って、関連する会話をまとめ、共有されるマシンの権限設定を行うことができます。1つのプロジェクトには、複数のチャットが含まれている場合もあります。別々の会話が同じコンテキストを持っているとは限りませんので、適切なプロジェクト内でチャットを移動させたり新規に作成したりしてください。アクティブなプロジェクトによって、Agentに対して会話の構造が伝えられます。

タグは会話を分類するものです。メッセージのブックマークは、個々のメッセージを指し示し、便利な結果に戻るための手段となります。これらは、会話を固定するという機能とは別のものです。チャットのタイトルや検索機能、アーカイブ機能、未読表示機能を使って、管理しやすいサイドバーを維持できます。

アーカイブ処理では、会話データを通常のリストから移動させるだけで、保存されている履歴は削除されません。必要な時には、アーカイブインターフェースからその会話データを復元することができます。会話データを削除すると、そのデータが破壊されてしまいますので、削除をアーカイブ処理の代わりとして使用しないでください。現在の実装では、SQLiteを使用して会話データを管理しています。古い圧縮されたHosted Chatアーカイブ形式を信じるべきではありません。

## メッセージの操作や、タスクの実行

利用可能なメッセージの操作は、そのメッセージと、現在の実行状態に依存します。適切な場合には、そのターンを編集したり、再試行したりすることができます。また、不要になったユーザーやアシスタントのターンを削除することもできます。削除すると、保存されている会話履歴が変わり、後のコンテキストにも影響を与える可能性があります。しかし、シェルコマンドやリモート操作、Gitでのプッシュ操作など、他の外部的な影響を元に戻すことはできません。

失敗した実行を再試行する際には、詳細なエラー情報を確認し、すでに完了しているツールの実行状況も確認してください。もし、切断前に書き込みが成功していた場合は、外部の状態を確認した上で、再度実行してください。もし、別のメッセージがキューに残っているか、あるいは別の処理が既に進行中である場合は、表示されているコントロールやステータスを利用してください。キューメッセージパネルを使えば、保留中の処理状況を確認できます。ステアリングコントロールは、現在実行中のツールが終了した後に、安全な範囲内でガイダンスを提供しようとします。どちらの操作も、既に完了したツールの効果を取り消すことはありません。

## 添付ファイル、プレビュー、およびアーティファクト

添付ファイルをアップロードするには、「Attachment Control」を使用します。アップロードの際、個々の添付ファイルのサイズは32MiBまでとなります。また、デプロイメントやプロキシのリクエストによって、実際の制限が変動する可能性があります。アップロードされたファイルは、Controllerに保存され、モデルを通じて参照できます。画像の処理には、画像データを受け入れるモデルやプラグインが必要です。アップロードされたファイルは、関連しないローカルやリモートのファイルへのアクセス権を与えるものではありません。

生成されたファイルを要求する際には、その保存先のパス、形式、内容を明確に指定してください。結果が存在していることを確認した上で、共有してください。チャット内で利用可能なアッンチャントやアーティファクトは、ダウンロードまたはプレビューすることができます。[ファイルリンク](../guides/file-links.md)を参照してください。

アーティファクトのレンダリングでは、React、HTML、SVG、Markdown、Mermaidといったコンテンツが、コードとして表示されるだけでなく、サイドパネルとしても表示されます。Agentアーティファクトの設定において、「Normal」モードでは標準的な指示が使用され、「shadcn/ui」モードではコンポーネントやライブラリに関するガイダンスが提供されます。「Custom」モードでは、組み込まれたアーティファクトの指示なしで、コンテンツをレンダリングできます。生成されたコードや表示された内容は信頼できないものと見なしてください。プレビュー外で使用する前に、必ずそれらを確認してください。ファイルベースのOfficeのプレビューやダウンロードは、生成されたUIアーティファクトとは異なります。

選択したモデルプロバイダーに送信する権限がない情報や、プライベートキー、または文書をアップロードしないでください。添付ファイルの削除やチャット内容の削除は、コンピュータ上のソースファイルを削除することとは別です。

## 好み/嗜好

チャットやユーザーの設定、例えばツールのオン/オフやキーボードショートカットなどは、WebUIを通じて管理され、実装されているサーバー上に保存されます。キーボードの動作を設定するには、「設定」を開きます。メッセージを送信するか、改行を行うかを区別してください。Agentの権限とは別に、チャットのツールのオン/オフも個別に設定できます。[ツールと権限](permissions.md)や[メモリとコンテキスト](context.md)も参照してください。
