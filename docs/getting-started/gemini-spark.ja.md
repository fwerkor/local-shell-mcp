# Gemini Spark / カスタム アプリを接続する

Gemini の **カスタム接続アプリ** 機能 (以前は **Spark** と説明されていました) を使用すると、資格のある Gemini ユーザーはリモート MCP サーバーに接続できます。 LSM は MCP エンドポイントを提供できます。これは、[unified web workspace](web-workspace.md)、[ChatGPT](chatgpt-connector.md)、およびその他の MCP クライアントに対する **代替クライアント接続**です。 LSM コントローラーの置き換えや導入は行いません。

Google は現在、カスタム アプリを **米国の 18 歳以上のユーザー**、**個人の Google アカウント**でログインし、**アクティビティを有効にしておくこと**に制限しています。この機能は**英語**で利用できます。接続は Gemini Web アプリで作成する必要がありますが、接続されたアプリは後でモバイルでも使用できます。可用性と UI ラベルは変更される場合があります。 [official Gemini custom apps instructions](https://support.google.com/gemini/answer/17209137) を参照してください。

## 接続する前に

- たとえば、[Docker Compose](../installation/docker.md) を使用して LSM ランタイムを開始し、その正常性を確認します。
- **パブリックにアクセス可能な HTTPS** を介して MCP エンドポイントを公開し、OAuth を有効にしたままにします。
- コントローラーの認証の詳細を把握し、必要なスコープのみを承認します。
- 制約のあるワークスペースまたはコンテナを使用します。 Gemini は、ファイル、マシン、端末に実際の影響を与える操作を要求する場合があります。

Gemini に入力するエンドポイントは次のとおりです。

```text
https://your-public-host.example.com/mcp
```

Web UI (`/ui`)、LibreChat URL、または `/mcp` のないサイトオリジンを入力しないでください。パブリック展開では、接続エラーを回避するために認証を無効にしないでください。

## 双子座でつながる

1. コンピューターで [Gemini](https://gemini.google.com/) を開き、対象となる個人アカウントでサインインします。
2. **[設定とヘルプ] → [接続されているアプリ]** を開きます。現在のインターフェースに応じて、**Personal Intelligence → Connected Apps** の下にある場合があります。
3. **カスタム アプリ** で、**カスタム アプリの追加** を選択するか、カスタム アプリの URL フィールドを使用します。
4. LSM HTTPS `/mcp` URL を貼り付け、**次へ** を選択します。
5. LSM コントローラーを使用して OAuth と同意のフローを完了します。 LSM は、OAuth 検出と動的クライアント登録をサポートしています。 Gemini が代わりに手動の OAuth クライアント認証情報を要求する場合は、続行する前に詳細オプションと LSM OAuth 設定を確認してください。
6. Gemini の会話で「`@`」と入力し、接続されているカスタム アプリを選択して LSM ツールを要求します。

「接続された LSM アプリを使用して環境を検査し、ワークスペース ファイルを一覧表示します。何も変更しないでください。」書き込み操作を試行する前に、ツールの結果とコントローラー監査を確認してください。

## 制限とトラブルシューティング

- **カスタム アプリのオプションなし:** アカウント、地域、年齢、言語、Keep アクティビティの資格を確認します。これは Gemini 側の可用性の制限であり、LSM 構成エラーではありません。
- **URL が拒否されました:** 外部からアクセス可能な HTTPS `/mcp` エンドポイントを使用します。 OAuth 検出とリバース プロキシを確認してください。
- **OAuth が失敗する:** LSM 認証画面、クライアント登録、コールバック URL、および付与されたスコープを確認してください。認証されていない MCP エンドポイントを公開しないでください。
- **ツールが見つからないか、失敗します:** クライアント側の MCP ツール/スキーマのサポートは異なる場合があります。単純な読み取り専用呼び出しを試し、LSM 監査とログを検査します。すべての Gemini クライアント機能との完全な互換性は保証されていません。
- **切断中:** 必要がなくなったら、**接続中のアプリ** に戻り、LSM を無効化、リンク解除、または削除します。

Google の [official guide](https://support.google.com/gemini/answer/17209137) では、最新のカスタム アプリのフローと可用性について説明しています。代わりにローカル CLI ベースの Gemini 統合については、[Gemini CLI's MCP documentation](https://geminicli.com/docs/tools/mcp-server/) を参照してください。 LSM [ChatGPT connector tutorial](chatgpt-connector.md) は引き続き個別に利用可能です。
