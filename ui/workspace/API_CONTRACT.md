before removing the independent `integrations/` service tree. It records route
names, **not** behavioral parity. Full end-to-end approval and SSE tests are
required before treating a route as implemented. Original implementation
remains accessible via repository Git history.

**Extracted route declarations:** 276. Mounted routers, dynamically
registered handlers, WebSockets, and SDK endpoints may add more routes.
